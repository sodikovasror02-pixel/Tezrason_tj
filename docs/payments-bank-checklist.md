# Пардохти воқеӣ: чӣ аз бонк гирифтан лозим

Сервер аллакай интерфейси тайёр дорад (`server/src/payments.ts` → `PaymentProvider`).
Барои пайваст ба бонки воқеӣ танҳо як класс навишта мешавад — боқӣ (ҳолатҳо, refund, webhook) тайёр аст.

## 1. Шартнома (эквайринги интернетӣ)
- [ ] Шартнома бо бонк-эквайер ё агрегатор: интернет-эквайринг (e-commerce), на POS-терминал.
- [ ] Кортҳои дастгиришаванда: **Корти Миллӣ**, Visa, Mastercard (ва ҳамёнҳо, агар бошад).
- [ ] Комиссия (%) ва мӯҳлати гузаронидани пул ба ҳисоби ширкат (T+1, T+2 …).
- [ ] Ҳуҷҷатҳо барои бонк: шаҳодатномаи бақайдгирӣ (ИНН), ҳисоби бонкӣ, сомона/барнома бо шартҳои истифода ва сиёсати бозгардонидани пул.

## 2. Аз бонк талаб кунед (техникӣ)
| Чӣ | Барои чӣ | Дар код |
|---|---|---|
| Ҳуҷҷати API (PDF/сомона) | эҷоди пардохт, ҳолат, refund | `createPayment`, `refund` |
| **Муҳити санҷишӣ (sandbox)** ва кортҳои тестӣ | санҷиш бе пули воқеӣ | — |
| Merchant ID / Terminal ID | муайян кардани фурӯшанда | env `BANK_MERCHANT_ID` |
| Калиди API ё сертификат (mTLS) | дастрасӣ ба API | env `BANK_API_KEY` (дар Render, на дар git) |
| Тарзи имзои webhook (HMAC-SHA256? RSA?) ва калиди он | санҷиши аслияти натиҷа | `verifyWebhook` |
| Суроғаи IP-и серверҳои бонк | маҳдуд кардани webhook | ихтиёрӣ |
| Refund-и қисман/пурра, мӯҳлати refund | бекор кардани фармоиш | `refund` |
| 3-D Secure (саҳифаи бонк) | талаби бехатарии кортҳо | `checkoutUrl` |
| Валюта ва воҳид (сомонӣ ё дирам) | маблағ | дар код ҳама дар дирам |

## 3. Ба бонк диҳед
- URL-и webhook: `https://<сервер>/payments/webhook`
- URL-и баргашт баъди пардохт (return URL): `tezrason://order/<id>` ё саҳифаи веб.

## 4. Баъди гирифтани ҳуҷҷатҳо
Ҳуҷҷати API ва калидҳои **sandbox**-ро диҳед (калидҳоро дар Render → Environment гузоред, на дар чат) —
класси провайдер навишта, бо тестҳои ҳозира (webhook, такрор, refund) санҷида мешавад.
